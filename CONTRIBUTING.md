# Contributing to BXP Protocol Website

Thank you for contributing to the BXP Protocol website (`bxpprotocol.github.io`).

This repository hosts the official BXP website, documentation, validator, and public assets.

## How to Contribute

### 1. Fork and Clone
```bash
git clone https://github.com/bxpprotocol/bxpprotocol.github.io.git
cd bxpprotocol.github.io
```

### 2. Make Changes
- Edit HTML files, markdown docs, or assets
- Test the validator locally by opening `validator.html` in a browser
- Ensure links resolve correctly

### 3. Submit a Pull Request
- Open a PR against `main`
- Describe what changed and why
- Reference any related issues from `bxpprotocol/bxp-spec`

## What We Accept

- Documentation improvements (typo fixes, clarity, translations)
- Validator enhancements
- New example datasets (`.bxp.json`)
- Website UI/UX improvements
- Asset additions (images, icons, styles)

## What We Do Not Accept

- Changes to the BXP specification (those go to `bxpprotocol/bxp-spec`)
- Proprietary or licensed assets without permission
- Personal data or real sensor readings (use synthetic data only)

## Code of Conduct

This project follows the [Contributor Covenant Code of Conduct](https://www.contributor-covenant.org/version/2/1/code-of-conduct.html).
