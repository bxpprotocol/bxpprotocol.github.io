# Security Policy — BXP Protocol Website

## Reporting a Vulnerability

Report security issues privately to **bxpprotocol@proton.me** with subject `BXP website security`.

Do not open public issues for security problems.

## Scope

**In scope:**
- Website HTML/JS (`index.html`, `validator.html`, `breathe.html`, etc.)
- Public assets (`manifest.json`, `feed.xml`, `sitemap.xml`, `robots.txt`)
- Documentation markdown files

**Out of scope:**
- Third-party APIs linked from the site
- User-deployed instances of the website
- The BXP specification (see `bxpprotocol/bxp-spec/SECURITY.md`)

## Supported Versions

Only the latest `main` branch receives security fixes.
