BXP sample dataset

Ten atmospheric exposure records in the BXP format, covering different agent combinations and quality flags. Published so integrators have concrete input to test against, and so the format is legible to people who work from data rather than from specifications.

These are not measurements Every record carries source: "simulated" and quality.flag: "UNVALIDATED". They exist to demonstrate the record structure. Do not use them for analysis, reporting, or any health decision. The classification is not decoration: SPEC.md 6.8 requires that provenance travel with the data, and a demonstration fixture presented as observational data is exactly what that rule exists to prevent.

Use it with the validator to confirm your own records parse, or with the Python SDK:

doc = read_bxp("sample_readings.bxp.json")   # keys ending _ are verification helpers

Converting from other formats

If your data is not already in BXP, start from the integration guide rather than hand-mapping fields:

  • OpenAQ v3 importer — included in the repository, converts OpenAQ locations and measurements to valid BXP records while preserving source provenance.
  • MQTT bridge — subscribes to a broker topic and emits BXP records, for live sensor output.
  • Postman collection — ready-to-use requests against any BXP node.
